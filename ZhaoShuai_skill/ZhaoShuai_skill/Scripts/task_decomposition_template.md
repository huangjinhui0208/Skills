# Task Decomposition Template

用于：问题逐渐清楚后，把它转换为可执行任务流。

## 目标
让复杂问题变成可以一步一步执行的清单。

## 拆解规则
- 每一步只处理一类判断
- 每一步都要有输入、动作、输出
- 每一步都要有“如何判断通过”
- 有分支时，必须写清转向条件
