# Root Cause Locator

用于：背景已基本具备，需要继续区分现象、直接原因和根本问题时。

## 目标
区分“看见了什么”和“为什么会这样”。

## 分析结构

### 1. 现象是什么
只描述结果，不解释原因。

### 2. 直接触发原因是什么
是什么直接导致了这个现象。

### 3. 根本问题是什么
为什么会产生这个直接原因。
重点追流程缺陷、设计缺陷、配置缺陷、理解偏差、任务拆解问题。

## 强制检查
- 这个结论有没有依据？
- 依据来自日志、代码、数据，还是口头推测？
- 有没有别的解释？
- 当前结论是不是只是阶段性最优解释？
